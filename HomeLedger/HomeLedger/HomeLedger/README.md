# HomeLedger — Домашняя бухгалтерия

Консольное приложение на C++17 для учёта личных доходов и расходов. Показывает баланс по кошелькам,
статистику и динамику, следит за месячными лимитами и предлагает способы организации трат
(правило 50/30/20, прогноз, дневной лимит, рост расходов к прошлому месяцу).

Требования: [srs/srs-homeledger.md](../srs/srs-homeledger.md).

## Возможности

| Пункт меню | Что делает |
|---|---|
| 1, 2 | Добавить расход / доход: сумма → категория → кошелёк → дата → комментарий (Enter — значение по умолчанию) |
| 3 | Перевод между кошельками (снятие наличных, пополнение копилки) |
| 4 | Журнал операций за месяц: `<` `>` — месяц, `к` — фильтр по категории, `и N` — изменить, `у N` — удалить |
| 5 | Статистика: по категориям с диаграммой, структура 50/30/20, динамика за 6 месяцев |
| 6 | Бюджеты: месячные лимиты по категориям, предупреждение при 80 % и 100 % |
| 7 | Советы по организации трат |
| 8 | Кошельки и категории (добавление своих) |
| 9 | Экспорт отчёта за месяц в CSV для Excel |

## Сборка

Нужен компилятор C++17 и CMake 3.16+. Сторонние библиотеки не используются.

**Visual Studio 2019/2022:** «Открыть локальную папку» → выбрать папку HomeLedger → «Сборка → Собрать всё».
Или из «Developer Command Prompt»:

```bat
cmake -S . -B build
cmake --build build --config Release
build\Release\HomeLedger.exe --demo
```

**MinGW-w64 (CLion, Qt Creator, MSYS2):**

```bat
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
build\HomeLedger.exe --demo
```

**Linux:**

```bash
cmake -S . -B build && cmake --build build -j
./build/ledger_tests          # модульные тесты
./build/HomeLedger --demo
```

Без CMake (один вызов компилятора):

```bash
g++ -std=c++17 -O2 src/*.cpp -o HomeLedger
```

## Параметры запуска

```
HomeLedger [--data КАТАЛОГ] [--demo] [--no-color] [--help] [--version]
```

* `--data` — каталог с данными (по умолчанию `data` рядом с местом запуска);
* `--demo` — заполнить пустой каталог демонстрационными данными за 6 месяцев;
* `--no-color` — без цветного вывода.

## Данные

Каталог данных содержит файлы `operations.csv`, `categories.csv`, `wallets.csv`, `budgets.csv`
(UTF-8, разделитель `;`). Изменения сохраняются сразу; при каждом запуске создаётся копия в `data/backup`.
Отчёт сохраняется в `data/report_ГГГГ-ММ.csv` и открывается в Excel двойным щелчком.

Программа не использует сеть и не хранит банковские реквизиты. Доступ к данным ограничивается
правами учётной записи Windows/Linux на каталог данных.

## Структура

```
src/
  Date, Money, Text     — даты, денежные суммы в копейках, UTF-8 и CSV
  Ledger                — модель: операции, категории, кошельки, лимиты
  Analytics             — статистика, состояния лимитов, советы
  Storage               — загрузка и сохранение CSV, резервная копия, экспорт
  Console, App, main    — консольный интерфейс
tests/tests.cpp         — модульные тесты логики (без сторонних библиотек)
```

Библиотека `ledger_core` (всё, кроме Console/App/main) не зависит от консоли и может быть использована
в графической версии (релиз 2).
