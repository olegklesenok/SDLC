# HomeLedger v1.0.0 — Домашняя бухгалтерия

Консольное объектно-ориентированное приложение на C++17 для ведения личного и семейного бюджета.
Разработано в рамках курса «Жизненный цикл разработки программного обеспечения» (БГУИР, гр. 434701, О. В. Клещенок).

## Возможности

- **Учёт операций и кошельков:** доходы, расходы и переводы между кошельками (`Наличные`, `Карта` и пользовательские); точная целочисленная арифметика в копейках.
- **Быстрый ввод из главного меню:** однострочная запись вида `-18,50 про хлеб и молоко` или `+250 подраб верстка сайта`.
- **Отмена последнего действия (`Undo`):** стек отмены до 15 операций (`u`).
- **Журнал и глобальный поиск:** помесячный просмотр, фильтр по категории, полнотекстовый регистронезависимый поиск по всей истории (с поддержкой кириллицы UTF-8), фильтр по датам, кошельку и сумме, редактирование и удаление с подтверждением.
- **Аналитика и Индекс финансового здоровья:** распределение расходов, правило **50/30/20**, профиль трат по дням недели, 6-месячная динамика, расчёт индекса финансового здоровья (0–100 баллов) и финансовой подушки безопасности в месяцах.
- **Бюджеты (лимиты):** месячные лимиты по категориям с мгновенным предупреждением при 80 % и 100 %.
- **Финансовые цели накоплений:** целевые суммы, сроки, пополнение с привязкой к расходам и расчёт рекомендуемого ежемесячного взноса.
- **Регулярные платежи и подписки:** шаблоны ежемесячных списаний и поступлений, индикация ожидающих платежей и проведение в одно действие.
- **Учёт долгов и займов:** контроль задолженностей («мне должны» / «я должен») с частичным/полным погашением и отражением в кошельках.
- **Экспорт и резервные копии:** отчёт для Excel (`.csv`, UTF-8 BOM, `;`), автономный интерактивный **HTML-дашборд** с векторными графиками SVG и клиентским фильтром, автоматические бэкапы при запуске и именованные снимки с восстановлением.

## Сборка и тестирование

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
.\build\ledger_tests.exe
.\build\HomeLedger.exe --demo
```
